🐛 COMMON ISSUES & FIXES
───────────────────────────────────────────────────────────────────────────

ISSUE: Profile image not showing
FIX: Make sure amarjeet-profile.jpg is in same folder as HTML

ISSUE: Theme not saving when I refresh
FIX: Check if LocalStorage is enabled in browser settings

ISSUE: Links not working
FIX: Make sure you didn't accidentally break the HTML structure

ISSUE: Looks weird on mobile
FIX: Zoom should be 100%. Clear browser cache (Ctrl+Shift+Delete)

ISSUE: Can't see changes after editing
FIX: Save file, then do Ctrl+F5 (hard refresh) in browser
